What it checks automatically

Every result comes with a plain-English explanation and what to do about it. Nothing on the Mac is changed.

Ownership locks
Activation Lock, company or school ownership, and remote management. Any of these can lock the Mac after you've paid.
Tampering
Disabled security features, hidden user accounts, remote login, and remote-control or tracking tools left behind.
Crash history
Whole-system crashes, which usually point to failing memory, storage or logic board. Check this before the seller erases the Mac.
Battery and charger
Charge cycles, real capacity in mAh against the original, condition, and whether the charger is genuine and actually charging.
SSD wear
How much of the drive's life is used, data written, hours powered on, and errors, read straight from the drive.
Wireless and parts
Wi-Fi reach, Bluetooth, camera, microphone and Touch ID. A part that doesn't show up is dead or disconnected.

Then test it by hand

Some faults only show up when you look, listen and touch. The app guides each one.

Screen and keyboard

Full-screen colours for dead pixels, and a keyboard map that lights up every key you press.

Speakers and trackpad

Left and right speaker tones, a bass sweep for rattles, and a Force Touch pressure meter.

Stress test

Three minutes at full power to reveal overheating, a weak fan or a board that crashes under load.

Ports and Bluetooth

Each USB-C port lights up when it detects a device, and a scan proves Bluetooth reaches nearby phones.

Using it at the seller's

  1. Bring the app on a USB stick

    Copy the DMG to a stick before you go, so you don't need the seller's Wi-Fi password to get started.

  2. Run the checks before anything is erased

    Crash history and leftover software disappear after an erase, so look at them first.

  3. Do the hands-on tests

    Screen, keyboard, speakers, trackpad, stress test and ports take about ten minutes in total.

  4. Watch the seller erase it, then pay

    After Erase All Content and Settings, setup must not ask for the seller's Apple Account or show a Remote Management screen.

Installing

  1. Open the DMG and drag Mac Check into Applications

  2. Open Mac Check

    Because the app is free and not distributed through Apple, macOS shows “Apple could not verify Mac Check”. Click Done.

  3. Allow it once

    Open System Settings › Privacy & Security, scroll down and click Open Anyway next to Mac Check. From then on it opens normally.

Copying the DMG from a USB stick formatted as ExFAT or FAT32 usually skips this prompt entirely, which is handy on a seller's Mac.

Questions

Is it safe to run on someone else's Mac?

Yes. It only reads information and changes nothing. The optional admin checks ask for the Mac's password through macOS's own dialog, so the seller types it, not you. All the code is open on GitHub.

Which Macs does it work on?

Apple Silicon Macs (M1 and later) running macOS 12 Monterey or newer. It doesn't support Intel Macs.

Does it need the internet?

No, except for one admin check that asks Apple whether an organisation owns the serial number, and Apple's warranty page.

Can it check the warranty automatically?

Apple doesn't offer a public way to do that, and its coverage page uses a CAPTCHA. Mac Check copies the serial number and opens the page, so you only paste it.

Does a clean report guarantee the Mac is perfect?

No tool can promise that. Mac Check catches the common deal-breakers and hidden faults, and Apple Diagnostics (hold the power button, then press ⌘D) covers the rest of the hardware.
