Using it at the seller's.

  1. Bring it on a USB stick

    Copy the DMG before you go, so you don't need the seller's Wi-Fi to get started.

  2. Check before anything is erased

    Crash history and leftover software disappear after an erase, so look first.

  3. Do the hands-on tests

    Screen, keys, speakers, trackpad, stress test and ports take about ten minutes.

  4. Watch the erase, then pay

    Setup must not ask for the seller's Apple Account or show a Remote Management screen.

Installing takes a minute.

Mac Check is free and isn't sold through Apple, so macOS asks you to confirm it once.

  1. Drag it into Applications

    Open the DMG and drag Mac Check onto the Applications folder.

  2. Open it and click Done

    macOS shows “Apple could not verify Mac Check”. That's expected.

  3. Click Open Anyway

    In System Settings › Privacy & Security, scroll down and click Open Anyway. It opens normally from then on.

Copying the DMG from a USB stick formatted as ExFAT or FAT32 usually skips this prompt, which is handy on a seller's Mac.

Questions.

Is it safe to run on someone else's Mac?

Yes. It only reads information and changes nothing. The optional admin checks ask for the password through macOS's own dialog, so the seller types it. All the code is open on GitHub.

Which Macs does it work on?

Apple Silicon Macs (M1 and later) running macOS 12 Monterey or newer. Intel Macs aren't supported.

Does it need the internet?

No, except for one admin check that asks Apple whether an organisation owns the serial number, and Apple's warranty page.

Can it check the warranty automatically?

Apple doesn't offer a public way to do that, and its coverage page uses a CAPTCHA. Mac Check copies the serial number and opens the page, so you only paste it.

Does a clean report guarantee the Mac is perfect?

No tool can promise that. Mac Check catches the common deal-breakers and hidden faults, and Apple Diagnostics (hold the power button, then press ⌘D) covers the rest of the hardware.
